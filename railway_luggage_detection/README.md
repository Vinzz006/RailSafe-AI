# RailSafe AI — AI-Powered Railway Luggage Detection System
### Smart India Hackathon (SIH 2026) | Problem Statement #26026
**Theme:** Mobile / Handheld Detection of Narcotics and Explosives Across Indian Railways  
**Subsystem:** Real-Time Computer Vision Luggage Screening & Unattended Baggage Monitoring

---

## ⚠️ Important Safety & Scientific Disclaimer

> **PROTOTYPE NOTICE:**  
> This software is a research and demonstration prototype designed solely for luggage monitoring, spatial tracking, and anomaly screening assistance.  
> **This system is NOT a certified explosive or narcotics detector.**  
> An optical USB webcam can only observe visible external bounding contours; **it cannot penetrate opaque bags or perform chemical spectrometry.** Alerts generated by this prototype indicate spatial observation anomalies (such as potentially unattended baggage) and **require mandatory physical human verification** under Indian Railways safety protocols.

---

## 1. System Overview

This application provides real-time computer vision capabilities using a laptop and a USB webcam (specifically calibrated for the **Zebronics ZEB-CRYSTAL PRO**).

### Core Features:
- **Real-Time Multi-Class Detection:** Uses Ultralytics YOLO to recognize people, backpacks, handbags, and suitcases.
- **Persistent Object Tracking:** Employs ByteTrack to assign persistent tracking IDs across consecutive video frames.
- **Unattended Baggage Proximity Intelligence:** Calculates the Euclidean distance from each bag's centroid to surrounding passengers. If a bag remains stationary without any accompanying person within the proximity perimeter for longer than the configurable threshold (default: **10 seconds**), an alert is raised.
- **Two Monitoring Interfaces:**
  1. **High-Tech OpenCV HUD (`main.py`):** Real-time overlay with bounding boxes, proximity lines, live FPS, status ticker, and keyboard shortcuts.
  2. **Interactive Streamlit Web Dashboard (`app_streamlit.py`):** Browser-based UI with live stream, dynamic parameter sliders, alert log table, and snapshot gallery.
- **Local Event Logging & Snapshot Capture:** Stores alerts in SQLite (`logs/security_alerts.db`) and CSV (`logs/luggage_alerts.csv`), and saves annotated snapshot frames to `snapshots/` without transmitting video externally.

## 5. How the Pipeline Works

```
USB Webcam (Zebronics ZEB-CRYSTAL PRO)
              |  640x480 @ 30 FPS
              v
[ 1. YOLO Detector & ByteTrack ]
  - Detects COCO Classes: Person (0), Backpack (24), Handbag (26), Suitcase (28)
  - Assigns unique, persistent tracking IDs (e.g. Bag #1, Person #3)
              |
              v
[ 2. Proximity & Proximity Distance Heuristic ]
  - For each bag, calculates minimum distance to nearest person bounding box
  - Proximity Threshold: ~160 pixels
              |
              v
[ 3. Unattended Luggage State Machine ]
  - Distance <= 160 px  --> Status: "Normal" (Accompanied)
  - Distance > 160 px   --> Status: "Isolated" (Timer starts)
  - Isolated > 10.0 sec --> Status: "Potentially Unattended — Review Required"
              |
              v
[ 4. Alert Logging & Snapshot Capture ]
  - Checks alert cooldown (15s per bag) to avoid duplicate frame alerts
  - Saves annotated JPEG snapshot to `snapshots/`
  - Inserts record into SQLite (`logs/security_alerts.db`) and CSV
              |
              v
[ 5. Security HUD Display / Streamlit Dashboard ]
  - Displays bounding boxes: Green (Person), Blue (Accompanied), Red (Unattended)
  - Renders live metrics, FPS, and operator alert ticker
```

## 7. Troubleshooting

### 1. Camera does not open (`Unable to open USB Webcam at index 0`)
- **Remedy 1:** Verify the Zebronics USB webcam is firmly connected.
- **Remedy 2:** In Windows Settings $\rightarrow$ Privacy & Security $\rightarrow$ Camera, ensure **"Let desktop apps access your camera"** is toggled **ON**.
- **Remedy 3:** If your laptop has a built-in webcam in addition to the USB webcam, the USB webcam might be at index `1`. Launch with:
  ```bash
  python main.py --camera 1
  ```
  Or press **`C`** during live monitoring to switch camera index.

### 2. Slow FPS / High CPU Usage
- Reduce the input frame dimensions in `config.py` (e.g., set `FRAME_WIDTH = 480`, `FRAME_HEIGHT = 360`).
- Ensure the lightweight model `yolov8n.pt` (nano) is used rather than larger weights (`yolov8m.pt` or `yolov8x.pt`).

### 3. False Positives (e.g., pillows, jackets detected as luggage)
- Press **`+`** in the application to raise the confidence threshold (e.g., from `0.35` to `0.50`).

## 8. Known Limitations & Next Steps

1. **Optical Occlusion:** If a passenger steps between the camera and their luggage, or if a bag is blocked by a bench, the distance calculation may temporarily overestimate separation.
2. **Crowded Railway Platforms:** In high-density crowds (e.g. NDLS platform during peak hours), simple geometric proximity may falsely associate a stranger standing near an abandoned bag. Future work should integrate multi-camera re-identification and human pose analysis.
3. **Future Hardware Integration:** In later phases of the SIH project, this computer vision pipeline will interface with the 4WD inspection rover, ESP32-CAM wireless video stream, and MQ multi-sensor telemetry backend to form a unified multi-modal security ecosystem.
